# 종목 비중 천장 — 품질등급(A/B/C) 폐기

품질등급 A/B/C는 **사이즈 캡으로 쓰이던 문제가 있어 전부 폐기**한다.
대신 **종목당 최대 보유 비중 20%**(유동자산=주식+현금 대비)만 기계적으로 적용한다.

## 캡 (유동자산 대비)

| 상태 | max % of liquid | 조건 |
|------|-----------------|------|
| **OK** | **20%** | 하드게이트 없음 |
| **금지** | **0% ADD** | 하드게이트 (아래) |

분모 = **주식 평가금 + 현금(USD+KRW환산)**. 주식만으로 나누지 않는다.

추가 한도:
- **종목천장 = 20%** (유동자산 대비 · 등급 차등 없음)
- **Top-3 합 ≤ 50%** (동일하게 유동자산 대비)
- **현금바닥 $150**

## 하드게이트 → 유효상태 `금지` (ADD 0%)

아래가 하나라도 있으면 **effective = 금지** (ADD 0%). 보유 비중 자체는 종목천장 20%(유동) 대비 OVER로만 표시한다.

- EARN_D5
- NO_ADD (보유 OS 기본)
- L1=0 / 강제패스
- 마진↓ / 가이드 C / 축소후보
- 업사이드 &lt; 0
- 손절(stop)·invalidation 없음
- 과열
