# 종목 비중 천장 — 품질등급(A/B/C) 폐기

품질등급 A/B/C는 **사이즈 캡으로 쓰이던 문제가 있어 전부 폐기**한다.
대신 **종목당 최대 보유 비중 20%**(주식 평가금 대비, 현금 제외)만 기계적으로 적용한다.

## 캡 (주식 평가금 대비)

| 상태 | max % of equity | 조건 |
|------|-----------------|------|
| **OK** | **20%** | 하드게이트 없음 |
| **금지** | **0% ADD** | 하드게이트 (아래) |

추가 한도:
- **종목천장 = 20%** (이전 A 절대천장과 동일 수준 · 등급 차등 없음)
- **Top-3 합 ≤ 50%**
- **현금바닥 $150**

## 하드게이트 → 유효상태 `금지` (ADD 0%)

아래가 하나라도 있으면 **effective = 금지** (ADD 0%). 보유 비중 자체는 종목천장 20% 대비 OVER로만 표시한다.

- EARN_D5
- NO_ADD (보유 OS 기본)
- L1=0 / 강제패스
- 마진↓ / 가이드 C / 축소후보
- 업사이드 &lt; 0
- 손절(stop)·invalidation 없음
- 과열

## SSOT

- `config/portfolio_watch.yaml` — 보유 `max_pct: 20` (종목천장). `grade` 필드는 선택·미사용(하드게이트만 유효)
- `src/sepa/position_grade.py` — `NAME_CAP=0.20` · OK|금지 · `weight_status` · `top3_over_cap`
- `src/sepa/portfolio_ops.py` — `HoldingRow.grade_label`, `apply_holding_grade`, 스텐스/리스크
- `포폴()` PDF — 종목 열에 `금지·ADD0·천장20%` / `종목천장20%` 형태 표시

## 운영 메모

- 현재 스냅(2026-09-22)은 **전원 NO_ADD** → 유효상태는 전부 금지. 표의 천장은 “게이트 풀리면 쓸 한도 = 20%”.
- 신규 매수 사이즈는 실행후보 BuyScore → `assign_from_buy_score` 후 **20%·현금여유·Top3**로 제한.
- TXG(~19.7%)만 천장 근접 · 그 외는 20% 미만이어도 Top3≈53.6% >50%가 리스크.
