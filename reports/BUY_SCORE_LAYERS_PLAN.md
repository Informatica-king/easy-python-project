# 실행후보 3레이어 점수표 — 개발 초안 보고서

**상태:** 초안 · **사용자 최종승인 대기** (승인 전 구현 착수 안 함)  
**작성일:** 2026-08-03  
**관련 OS:** 규칙형 챌린저 모멘텀 생존 OS  
**선행 문서:** `reports/PORTFOLIO_OPS_PLAN.md` (`포폴()`)

---

## 0. 한줄 목적

기존 `포폴()` 매수고려(실행후보 / 워치 / 금지)는 **유지**하고,  
실행후보 집합 위에 **순위·사이즈·실적 후 타이밍**만 얹어  
“같은 후보 풀에서 덜 헛치고 산다”를 구현한다.

> 예언기가 아니라 **선택 집중 장치**.

---

## 1. 배경 · 왜 필요한가

| 지금 | 문제 |
|------|------|
| A′ 실행후보가 2개면(예: CMPR·LAUR) 거의 동등 | 어디에 총알을 모을지 불명확 |
| 점유 가산은 Chase 점수·코멘트에만 | 매수 **실행 순위**와 약하게 연결 |
| 실적 후는 “홀드/관망” | 가이드 해석 프로토콜 없음 |

생존 규칙(물타기·EARN_D5·비중·NO_ADD)은 이미 강함.  
고수익 쪽은 **필터 강화가 아니라 실행 집중**이 병목.

---

## 2. 합의된 조립 (변경 범위)

### 2.1 안 바꾸는 것 (하드 제약)
- 물타기 금지 · EARN_D5 신규/분할 차단 · 코어≤20% · 위성≤10% · 현금바닥 $150  
- 갭 추격 금지 · 보유 NO_ADD  
- 심층 → A′/B/SOFT → 포폴 1차 필터(금지/워치/실행) **파이프라인 유지**

### 2.2 바꾸는 것 (소프트 레이어)
실행후보에만 적용하는 3레이어:

| # | 레이어 | 역할 |
|---|--------|------|
| L1 | **상대강도 (RS)** | 시장·섹터 대비 진짜 모멘텀인가 |
| L2 | **점유↑ + 마진유지** | 챌린저 품질 (이미 `share_gain`과 정합) |
| L3 | **실적 후 가이드 등급** | D+1~D+3 해석 프로토콜 (갭매수 아님) |

## 3. 점수표 초안 (설계)

### 3.1 적용 대상
- **입력:** `포폴()`이 만든 `실행후보` 리스트만  
- **워치/금지:** 점수 계산 안 함 (표시만)  
- **보유 NO_ADD:** 계속 금지 (점수 무관)

### 3.2 L1 — 상대강도 (자동)

**정의 (v1)**  
- 창: 최근 **63거래일(~3M)** 및 **21거래일(~1M)**  
- 벤치: **SPY** + 종목 섹터 ETF(있으면; 없으면 SPY만)  
- \( RS = r_{ticker} - r_{bench} \) (단순 수익률 차이)

**점수 (0~2)**

| 조건 | 점 |
|------|----|
| 3M RS > 0 **그리고** 1M RS > 0 | +2 |
| 둘 중 하나만 > 0 | +1 |
| 둘 다 ≤ 0 | 0 → **실행 보류(패스)** 권고 |

**하드 규칙 (권고):** L1 = 0 이면 실행후보라도 **이번 주 매수 패스** (워치로 강등 표기).

### 3.3 L2 — 점유↑ + 마진유지 (반자동/프로필)

**데이터:** `sepa.share_gain` + `PEER_PROFILES` (기존)  
마진: 프로필/공시 기반 `margin_delta_pp` (없으면 `unknown`)

**점수 (0~2)**

| 조건 | 점 |
|------|----|
| Δ점유 ≥ +0.3pp **그리고** 마진유지(≥0) | +2 |
| Δ점유 ≥ +0.3pp · 마진 unknown | +1 |
| Δ점유 ≥ +0.3pp · 마진악화 | **0 + 실행 제외** (기존 가산취소와 동일 정신) |
| Δ점유 < +0.3pp 또는 프로필 없음 | 0 (감점 아님, 순위만 밀림) |

### 3.4 L3 — 실적 후 가이드 등급 (반자동)

**창:** 실적일 **D+1 ~ D+3** (캘린더)  
**갭 당일 매수: 금지 유지**

| 등급 | 기준(초안) | 운영 |
|------|------------|------|
| **A** | 가이던스↑ 또는 명확한 톤 상향 + 큰 미스 없음 | 홀드 · 익절목표 상향 관찰 · **추가금지 유지** · 눌림 시에만 위성 재검토 |
| **B** | 인라인 / 혼조 | 홀드 · 계획 없음 |
| **C** | 가이던스↓ · 톤악화 · 큰 미스 | **축소 후보**로 포폴 리스크 스트립 표시 |
| **N/A** | 실적창 밖 · 미발표 | 레이어 미적용 (점수 중립) |

**점수 반영 (실행후보 정렬용, 0~1)**  
- A: +1 · B: 0 · C: 실행 점수 계산 대상에서 제외(보유 축소 트랙) · N/A: 0

> L3는 “새로 사기”보다 **보유 해석 + 실행후보가 실적 직후인 경우의 타이밍**에 초점.

### 3.5 종합 정렬 키

```
total = L1(0–2) + L2(0–2) + L3(0–1)   → 최대 5
```

**정렬:** `total` 내림차순 → 동점이면 업사이드 → 동점이면 A′ 우선(B보다)

**사이즈 가이드 (위성 한도 안)**

| total | 권고 |
|-------|------|
| 4–5 | 실행 1순위 · 위성 기본 사이즈 |
| 2–3 | 극소 또는 워치 유지 |
| 0–1 | 패스 |
| L1=0 또는 L2 마진악화 | 패스 |

**월간 최소 실행(선택, 승인 시):**  
필터가 과하면 현금만 쌓임 → “달에 1회, total≥2인 A′ 극소 1건” 옵션을 문서에만 남겨 두고 **기본 OFF**.

## 4. `포폴()` UI 변경 (보고서 섹션)

### 4.1 섹션 3 개편
기존: 실행후보 / 워치 / 금지 표  

추가 컬럼(실행후보만):

| 티커 | 게이트 | L1 RS | L2 점유·마진 | L3 가이드 | total | 권고 |
|------|--------|-------|--------------|-----------|-------|------|

### 4.2 액션 3줄 연동
- 할 일: `실행 1순위: TICKER (total=X)` 또는 `이번 주 실행 없음`  
- 하지 말 일: L1=0·마진악화·EARN_D5 재강조  
- 다음 체크: 임박 실적 D+1~3 등급 입력 상기

### 4.3 실적 후 등급 입력 (v1)
- 경로(안): `data/earn_guide_grades.yaml`  
  ```yaml
  as_of: "2026-08-06"
  grades:
    ECPG: { grade: A, note: "가이드↑ collections", graded_on: "2026-08-06" }
  ```
- 없으며 L3=N/A  
- 나중에 심층 코멘트 파서로 반자동화 가능 (v2)

## 6. 구현 순서 (승인 후)

1. `BuyScore` + L2 연동(오프라인) + 테스트  
2. L1 RS (yfinance, SPY±섹터) + 실패 시 L1=unknown→보수적으로 0 또는 1(정책: **실패=1점 중립** 제안)  
3. L3 yaml 로드 + D+1~3 윈도우  
4. `포폴()` 표/액션 반영 · 샘플 PDF  
5. 한글 커맨드 동작 확인 · 릴리즈

**L1 데이터 실패 정책 (초안):** 네트워크 실패 시 `L1=1(중립)` + freshness 경고.  
완전 실패를 0으로 두면 매수가 과도하게 막힐 수 있음.

## 7. 성공 기준

| 기준 | 통과 조건 |
|------|-----------|
| 비회귀 | 기존 금지/NO_ADD/EARN_D5 동작 동일 |
| 순위 | 실행후보 ≥2일 때 total로 **1순위가 유일**하게 표시 |
| 가드 | 마진악화·L1=0 → 권고=패스 |
| 실적 | 등급 C면 축소 스트립에 티커 등장 |
| 문서 | 포폴 표지에 OS 한줄 + 점수 범례 1줄 |

## 8. 리스크 · 완화

| 리스크 | 완화 |
|--------|------|
| 필터 과다 → 매수 0 | 패스는 “권고”; 강제 차단은 L1=0·마진악화·기존 하드룰만 |
| RS 단기간 노이즈 | 1M+3M 동시 조건 |
| 점유 프로필 없는 종목 | L2=0으로 순위만 밀림 (금지 아님) |
| 가이드 등급 주관 | yaml에 note 필수 · 등급 정의 표를 리포트에 고정 |
| 심층 freshness | 기존 freshness 경고 유지 · 점수와 별개 |
