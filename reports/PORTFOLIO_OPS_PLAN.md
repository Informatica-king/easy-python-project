## 1. 한줄 정의

`포폴()` = **내 확정 보유 스냅 + 최근 종가**로 비중·리스크·이벤트를 보고,  
**최신 심층(Chase 본선 ∩ 타이밍 GO)** 을 포폴 규칙으로 걸러 **실행 가능한 운영 브리프**를 만든다.

`심층분석()` = 유니버스 조사 · `기술적분석()` = 셋업 점수  
`포폴()` = **내 책(book) 운영 OS**

## 2. 합의된 범위 (확정)

| 항목 | 합의 |
|------|------|
| 시각화 | 파이 2종: **주식만** / **주식+현금** |
| 지수 비교 | **현재 스냅 보유 바스켓** vs **나스닥(QQQ 또는 ^IXIC)** · **S&P500(SPY 또는 ^GSPC)** |
| 스냅 표 | 최근 종가 · 수량 · 평단 · 평가 · 비중 · 스텐스 코멘트 |

| 추가 | 리스크 스트립 · 금지/홀드 박스 · 데이터 freshness · 액션 3줄 |
| SSOT | 최신 확정 포트 스냅 1곳만 사용 (날짜·출처 표기) |

## 3. 데이터 입력 (SSOT)

### 3.1 포트 스냅 (필수)
- 경로(안): `config/portfolio_watch.yaml` → 발전 시 `data/portfolio_snap_YYYYMMDD.json`
- 필수 필드(종목): `ticker, shares, cost(평단), grade, max_pct, stop, tp1/tp2?, no_add, earn_date?, band?, invalidation?`
- ~~sleeve(core/satellite)~~ → **폐기**. 비중은 A/B/C/금지 기계 등급 (`reports/POSITION_GRADE_SIZING.md`)
- 필수 필드(북): `as_of, cash_usd, cash_floor_usd(=150), note/source`
- **현금은 추정 금지** — 스냅의 `cash_usd`만 사용. 없으면 주식-only 파이만 그리고 경고.

### 3.2 시세 / 이벤트
- 최근 종가·벤치 시계열: yfinance
- 실적일: 스냅 `earn_date` = **confirmed SSOT** · yfinance/rank = **estimate** (하드 EARN_D5는 확정만)

### 3.3 심층·매수 게이트 (최신 파일 자동 선택)
- `reports/buy_scenarios_YYYYMMDD.json` (`sepa.buy_scenarios` / thin `scan_buy_scenarios_*.py`)
- `reports/chase_rr_YYYYMMDD.json` / `rank_*.json` / `qual_*.json`
- (있으면) `reports/ta_YYYYMMDD.csv`
- freshness: 심층 as_of가 N일(기본 5영업일) 이상이면 매수고려에 **신뢰↓ 경고**

## 4. 리포트 구성 (페이지 순서)

```
표지
  · as_of · 스냅 출처 · 주식평가 / 현금 / 유동합계
  · 리스크 스트립 (EARN_D5·stop근접·과비중·현금바닥)
  · 금지/홀드 박스
  · 액션 3줄 (오늘 할 일 / 하지 말 일 / 다음 체크)

0. 시각화
  · 파이 A: 주식만 비중
  · 파이 B: 주식+현금 비중 (+ 현금바닥 $150 표시)
  · 포폴 바스켓 vs QQQ·SPY (스냅일=100 누적수익률, 현금 제외 가중)

1. 현재 스냅 표
  · 수량·평단·종가·평가·비중(주식/유동)·손익%·등급(품질→유효)·스텐스

2. 이벤트 캘린더
  · 종목별 실적일 · D-5 시작 · 임박 플래그
  · 포트 공통: 월적립(10일) 등

3. 매수고려 (필터 후)
  · 실행후보 | 워치 | 금지  (근거: 본선∩GO / WAIT · 업사이드 · 확정EARN_D5 · NO_ADD · 과열)

4. 운영 계획
  · 금토일 → 차주(월~금)
  · 그 외 → 향후 5영업일
```

## 5. 핵심 계산 정의

### 5.1 비중
- 종목평가 `value = shares × last_close`
- `w_stock = value / Σstocks` (파이 A)
- `w_liquid = value / (Σstocks + cash_usd)` (파이 B)
- OS 한도 판정 기준: **주식 평가금 대비** (기계 등급)
  - A ≤18% · B ≤10% · C ≤6% · 금지 = ADD 0%
  - 절대천장 20% · Top-3 합 ≤50%
  - SCHD 목표 0 (청산 · 완충=현금)

### 5.2 포폴 지수 (벤치 비교)
- 구성: **현재 주식 보유** (현금 제외)
- 가중: 스냅 시점 `w_stock` 고정(또는 일별 리밸런스 없음 = buy&hold 수량 고정)
- 시작점: 스냅 `as_of` 종가 = 100
- 비교: **QQQ(나스닥100 대용)** · **SPY(S&P500 대용)**  
  - 필요 시 차트 주석에 `^IXIC`/`^GSPC` 병기 가능하나 1차는 ETF로 통일
- 고지: “현금·중간매매 미반영 근사 · 투자권유 아님”

### 5.3 스텐스 코멘트 (규칙 자동)
우선순위 예:
1. STOP 근접/이탈 → 축소검토  
2. EARN_D5 → 추가금지·관망  
3. NO_ADD / 비중OVER(품질한도) / 유효금지 → 추가금지  
4. TP1 이상 → 익절검토  
5. 그 외 → 홀드 / 워치

### 5.4 매수 필터
심층 후보에서 제외 또는 ‘금지’로 강등:
- 보유 + `no_add`
- **확정** EARN_D5 (추정일은 주의만)
- Chase 과열/매도/중하 (본선 제외)
- 업사이드 음수(기본 제외, 예외 표시 가능)

남으면:
- **본선 ∩ 타이밍 GO** → **실행후보** (등급한도 A/B/C·현금바닥 여유 · 저녁창 지정가 카드)
- **본선 ∩ WAIT** → **워치** (삭제하지 않음 · GO_B 프리마켓 기본 WAIT)
