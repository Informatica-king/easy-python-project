# 실험 계획서 — RS×Fund 영역별 S&P500 상대수익률

> **상태**: 설계안 (실행 전 — 사용자가 실험 선택)  
> **작성일**: 2026-07-28  
> **동기**: RS–Fund 산점도에서 “점수 높은 영역 = 단기 초과수익”이 성립하는지 의심됨.  
> **질문**: *어느 RS×Fund 영역이 최근 2주 / 1개월 / 3개월 / 6개월 동안 S&P500 대비 상대수익률이 좋았는가?*

---

## 0. 한 줄 결론 (설계 전제)

**높은 Fund / 높은 RS는 “지금 당장 단기 수익을 보장”하는 신호가 아닐 가능성이 큽니다.**  
Fund는 실적 가속·품질, RS는 *이미 오른* 상대강도입니다. 둘 다 **선행 단기 수익률 예측기**로 설계되지 않았습니다.  
이 실험은 “보장”을 증명하려는 게 아니라, **어느 영역이 과거에 SPX를 이겼는지 / 점수가 단기 초과와 얼마나 무관한지**를 숫자로 확인하려는 것입니다.

---

## 1. 배경 — 이미 있는 것 / 없는 것

| 기존 자산 | 내용 | 이번 질문에 대한 한계 |
|---|---|---|
| `analyze` RS×Fund 산점도 | 당일 평균으로 4분면 시각화 | 영역 ID·수익률 없음 |
| `model_metrics.compute_quantile_forward_returns` | Fund **1차원** 분위수, forward **1/5/20일**, 벤치 **NASDAQ/^IXIC** | 2D 영역 없음, SPX 없음, 2주·1·3·6개월 없음 |
| `sepatop` | 현재 멤버십으로 만든 지수 vs `^GSPC` | PIT(시점 고정) 영역 백테스트 아님 |
| `reports/fundamental_*.csv` | 2026-07-16 ~ 07-28 **약 12스냅샷** | 대부분 RS≥80 시대; 07-27부터 RS≥70+soft ceiling. **3·6개월 forward 불가** |
| `rs_study/fundamental_tech_*` | RS 게이트 전 tech Stage2 채점 1회 | 날짜 1개 — trailing 맵핑용 보조 |

**핵심 제약:** “과거 점수 → 이후 3/6개월 수익”을 **저장된 스냅샷만**으로 돌리면 표본이 부족합니다.  
진짜 예측력 검증에는 **과거 as-of 재구성** 또는 **trailing(이미 나온 수익을 오늘 좌표에 칠하기)** 중 하나를 택해야 합니다.

## 2. 두 가지 해석 (먼저 고를 것)

같은 문장이라도 실험이 갈립니다.

| ID | 해석 | 답하는 질문 | 예측력? |
|---|---|---|---|
| **T** Trailing | *오늘(또는 특정일) RS–Fund 좌표*에, 각 종목의 **최근** 2주/1/3/6개월 SPX 대비 초과수익을 칠한다 | “지금 맵에서 **이미** 잘 오른 곳은?” | ❌ 사후 |
| **F** Forward | *과거 점수일 T*의 영역 → **이후** h일 SPX 대비 초과 | “그 영역이 **앞으로** 좋았나?” | ✅ 예측 |

사용자 의심(“점수 ↑ ≠ 단기 수익 보장”)을 직접 검증하려면 **F가 본게임**입니다.  
다만 F는 데이터·공수가 크고, T는 빠르게 “맵과 최근 성과의 어긋남”을 눈으로 보여 줍니다.

**권장:** T로 직관을 확인 → 선택한 영역 정의로 F(축소판) 검증.

## 3. 공통 설계

### 3.1 벤치마크

- **주 벤치:** S&P500 `^GSPC` (실패 시 `SPY`)
- 종목 초과: \( r_i - r_{\mathrm{SPX}} \) (단순 차감, 기존 fund_study/model_metrics와 동일 계열)
- 보조(선택): NASDAQ `^IXIC` — 유니버스가 나스닥이라 참고용

### 3.2 보유 기간 (거래일 근사)

| 라벨 | 거래일 h | 비고 |
|---|---:|---|
| 2주 | 10 | |
| 1개월 | 21 | |
| 3개월 | 63 | |
| 6개월 | 126 | |

가격: `data/raw/{TICKER}.parquet` 종가. 상장·결측은 해당 구간 제외.

### 3.3 유니버스 (후보)

실험마다 하나를 고정해야 공정합니다.

| 유니버스 | 정의 | 장단 |
|---|---|---|
| **U1 Live GO** | 당일 `fundamental_*.csv` (RS≥70 + soft ceiling 후) | GO와 동일, **저RS 영역 없음** |
| **U2 Broad Stage2** | TT 1–7 통과 + Fund 채점 (`fundamental_tech`류, RS 게이트 전) | 산점도 하방·좌측까지 채움 — **영역 연구에 적합** |
| **U3 유동성 유니버스** | 히스토리·유동성만 통과한 전 종목 + RS·Fund | 가장 넓음, 채점 비용 큼 |

**권장 기본:** **U2** (영역 비교가 목적일 때). GO 운용 검증만 보면 U1 병행.

### 3.4 영역(셀) 정의 — 택1 또는 병행

산점도 “어디”를 말하려면 경계를 고정해야 합니다. 당일 평균 4분면만 쓰면 날마다 칸이 움직여 비교가  непро明합니다.

| 방식 | 정의 | 추천 |
|---|---|---|
| **R1 고정 격자** | RS: `[0,70), [70,80), [80,90), [90,100]` × Fund: `[0,25), [25,50), [50,75), [75,100]` | ✅ 해석·재현 쉬움 |
| **R2 분위수 2D** | 스냅샷 내 RS·Fund 각각 사분위 → 4×4=16셀 | 표본 균등, 절대점수 의미는 약함 |
| **R3 운용 4분면** | 당일 평균 RS/Fund로 High-High / High-Low / … | 차트와 동일, **시계열 비교 약함** |
| **R4 밴드+품질** | RS 70–89 vs ≥90(+Fund조건) 등 **현재 live 정책 구간** | 정책 검증용 |

**권장:** 메인 **R1**, 보조로 live 정책 **R4**. R3는 “오늘 차트 주석”용.

### 3.5 집계 지표 (셀마다, 기간마다)

- \(n\), 평균·중앙 **초과수익률**
- **승률** \(P(r_i > r_{\mathrm{SPX}})\)
- (선택) 동일가중 포트 초과, 부트스트랩 CI
- (선택) Fund만 / RS만 1D 슬라이스 — “2D가 1D보다 나은지”

**명시적 귀무가설:** 셀 간 평균 초과의 차이가 없다 / Fund·RS와 단기 초과의 상관이 ≈ 0.

## 4. 실험 메뉴 (선택용)

비용·해석 강도 순. **원하시는 ID만 골라 주시면 그다음 구현·실행**합니다.

### 실험 A — Trailing 히트맵 (빠름, 사후)

- **설계 T + U2(또는 U1) + R1**
- 최신 스냅샷(또는 `fundamental_tech`) 좌표에 과거 10/21/63/126일 SPX 초과를 색칠
- 산출: 기간별 히트맵 PNG, 셀 요약 CSV, 산점도에 초과 버블/색상 오버레이
- **읽기:** “고점 영역이 최근에도 이겼는지” 시각 확인. **미래 보장 아님**
- 공수: 소 | 의존: 가격 캐시 + 1회 넓은 Fund 점수(없으면 tech 재사용/재채점)

### 실험 B — 짧은 Forward (보유 스냅샷만)

- **설계 F**, 스냅샷 `fundamental_20260716`~`0728`
- 가능한 Horizon: 사실상 **2주(10일)** 위주 (1개월은 초반 스냅샷만 부분)
- 벤치 SPX, 영역 R1 또는 Fund 분위(기존 코드 확장)
- **읽기:** “최근 2주, 고Fund가 앞섰나?”에 대한 **아주 짧은** 증거
- 공수: 소~중 | **한계: 3/6개월·일반화 불가**, RS 정책 변경(80→70)으로 표본 이질

### 실험 C — As-of 재구성 Forward (본게임, 큼)

- 과거 여러 as-of(예: 월말 또는 격주)에 TT+Fund를 **그 시점 가격**으로 재계산 → R1 셀 → forward 10/21/63/126 vs SPX
- as-of 개수 제안: 최소 **12개** (약 6개월 격주) 또는 **6개** 월말
- **읽기:** 점수/영역이 단기·중기 초과를 **예측했는지**에 가장 가깝게 답함
- 공수: 대 | **주의:** 펀더멘털(분기·surprise)이 최신 캐시면 **룩ahead** 가능 →  
  - C1: 가격·RS만 PIT, Fund는 “가용 최신”(빠른 근사, 편향 가능)  
  - C2: 분기 보고서 일자로 Fund PIT 근사(정밀, 공수↑)
- 권장 1차: **C1 + U2 + R1**, horizon 전부, SPX

### 실험 D — “점수 ↑ ≠ 단기 수익” 직접 검증

- A 또는 C의 데이터로:
  1. Spearman(Fund, 초과), Spearman(RS, 초과) — horizon별  
  2. 고Fund 분위 vs 저Fund 분위 초과 차이 (기존 quantile fwd를 SPX·장기 h로 확장)  
  3. High-RS∩High-Fund vs 나머지
- **성공 기준(예시):** 단기(10·21일)에서 Fund–초과 상관 ≈ 0 또는 음수여도 “모델 실패”가 아니라 **설계 범위 밖**으로 문서화
- 공수: A/C에 붙는 소량 분석

### 실험 E — Live 정책 구간만 (R4)

- 셀: `RS 70–89` / `RS≥90 & Fund≥med` / (참고) soft ceiling 탈락군  
- Trailing(A) 또는 Forward(B/C)
- **읽기:** 지금 GO 규칙이 “최근 상대성과”와 맞는 쪽을 담는지
- 공수: 소 (A에 옵션으로 묶을 수 있음)

### 실험 F — 하지 말 것 (이 질문에는 부적합)

- 현재 멤버십 `sepaTop` 곡선을 “영역 성과”로 해석하기 (구성 생존·시점 편향)
- 스냅샷 12개만으로 6개월 forward 일반화 주장
- 벤치 없이 절대 수익률만으로 “성장 가능성” 단정

## 8. 예상되는 “솔직한” 결과 메시지 (가설)

실험 전 가설이며, 결과가 다르게 나오면 가설을 폐기합니다.

1. **단기(2주·1개월):** Fund 고점 영역이 SPX 초과를 **체계적으로 보장하지 않음** (상관 약함·혼재).  
2. **고RS 영역:** 이미 반영된 모멘텀이라 trailing에는 강해 보여도, forward에서는 **평균회귀·연장 부담**이 섞일 수 있음.  
3. **중기(3·6개월):** “실적 가속 + 적당한 RS(예: 70–89)”가 고RS·저Fund보다 나을 **여지**는 있으나, 단일 국면(2026 중반)만으로는 단정 금지.  
4. 따라서 모델 사용법: **스크리닝·우선순위**이지 **단기 매수 타이밍 보증**이 아님 — VCP/리스크 관리와 분리.
