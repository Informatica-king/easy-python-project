# ECG vs 기존 필터 우선순위 (D34 Phase B3)

> 상태: **운영 정책** (2026-10-05)  
> 전제: Phase A4 = **자료 부족**(플러스 신호) · ECG는 **본선 교체 아님** · Fund 식 미수정

이 문서는 `!sepa.go` / `!sepa.anal`에서 **어느 규칙이 이기고**, 출력이 **왜 두 줄인지**를 고정한다.

---

## 1. 레이어 순서 (앞이 먼저 · 뒤가 앞을 번복하지 못함)

| 순위 | 레이어 | 역할 | 번복 |
|------|--------|------|------|
| **L0** | 유니버스·유동성 | 가격·거래대금 하한 | — |
| **L1** | Stage 2 + RS≥70 | 가격 확인 (C1) | — |
| **L2** | 후보 필터 | Fund>0 · 시총≥$1B | — |
| **L3** | **RS soft ceiling** | RS≥90이면 Fund≥풀 중앙값만 유지 | **본선 탈락은 최종** |
| **L4** | sepaTop 풀 | L3 통과군 = 지수·멤버십 본선 | ECG가 멤버십을 바꾸지 않음 |
| **L5** | median+ | L4 중 Fund≥중앙값 · **필수 복사용 한 줄** | ECG와 **병행** (교집합 강제 아님) |
| **L6** | **ECG 추천 (B1)** | L3 통과군 안에서 G3c ∩ ECG 상위 25%(10–30) | **참고 레이어** |

**한 줄:** soft drop된 종목은 ECG 점수가 높아도 **추천에 재진입하지 않는다.**

코드: `sepa.ecg.load_soft_drop_tickers` + `select_ecg_recommend(exclude_tickers=…)`.  
입력 `fundamental_*.csv` 자체가 이미 L3 이후라 일상적으로는 빈 집합이지만, **이중 차단**이다.

## 2. 충돌 표

| 상황 | 누가 이김 | 출력 |
|------|-----------|------|
| RS≥90 · Fund&lt;중앙값 (soft drop) | **soft ceiling** | 본선·ECG 추천 **모두 제외**. `rs_soft_drops_*.csv`에만 남음 |
| L3 통과 · Fund&lt;중앙값 · ECG 상위 | **둘 다 유효** | median+에는 없음 / **ECG 추천에는 있을 수 있음** (초입 Path B) |
| L3 통과 · Fund≥중앙값 · ECG 하위 | **둘 다 유효** | median+에는 있음 / ECG 추천에는 없을 수 있음 |
| L3 통과 · 둘 다 상위 | 충돌 없음 | 양쪽에 등장 (교집합은 우연) |
| “go 결과를 ECG만으로 교체” | **금지** (A4·B 본선 미통과) | 기존 한 줄 + ECG 한 줄 **병기** |

2026-10-05 스모크: soft drop 18종 ∩ ECG 추천 15종 = **0**. 정책과 일치.

---

## 3. 의도적으로 겹치지 않는 것

- **median+ ≠ ECG 추천.** Jaccard가 낮을 수 있다 (같은 날 ~0.15). 버그가 아니라 **다른 축**.
- ECG Confirmed G3c는 median 이상이 **또는** 얕은 B/D + Fund≥30.  
  → 중앙값 아래 초입이 추천에 들어오는 것은 **허용**.
- 그 초입이 **soft drop**(고RS·저Fund)인 경우는 **허용하지 않음**.  
  고RS 연장 + 약한 Fund는 “초입”이 아니라 기존 정책이 자르려던 구간.

## 4. UX 규칙 (go 출력)

1. **[필수] median+** 복사용 한 줄 — 생략 금지 (기존 하드 룰).  
2. **[ECG 추천 · B1]** 복사용 한 줄 — 참고. 본선 교체 문구 금지.  
3. **[B2] ECG/CSS 한 줄** — 마지막 CSS Δ · `자료 부족` 라벨 유지.  
4. sepaTop 차트/멤버십은 L4 기준. ECG가 지수를 재정의하지 않음.

## 5. 바꾸려면 (아직 하지 말 것)

| 변경 | 필요 조건 |
|------|-----------|
| ECG를 go **본선**으로 덮어쓰기 | n_asof≥20 + S2/S4 유지 + 사용자 명시 승인 |
| `median+ ∩ ECG`를 **유일한** 복사용 한 줄로 | 별도 UX 승인 (지금 하드 룰과 충돌) |
| soft drop을 ECG로 **구제** | **금지** (이 문서가 막는 핵심) |
| Fund 식 변경 | Phase C만 |
