# 모델 개선 계획 — 확인된 초입 성장 선별 + 다팩터 성공 점수

> **상태**: Phase A0 **승인 완료** (2026-10-05) · Phase A1 **구현** · A2 대기  
> **결정 로그**: **D34**  
> **관련**: `docs/strategy_spec.md`, `docs/fundamental_spec.md`, `docs/asof_forward_bt.md`, `docs/perf_study_framework.md`

## 0. 한 줄 목표

**성장이 “이제 막 확실해진” 종목에 올라탄다.**  
그 선별·성적 판단을 **여러 팩터로 종합 점수화**하고,  
**Fund 함수 본문 수정은 그 다음 단계**로 미룬다.

---

## 1. 사용자 확정 방향 (입력)

| # | 확정 내용 | 설계 함의 |
|---|---|---|
| **1** | **확인된 성장**만 본다. 그중 **이제 막 성장이 시작**됐다고 판단된 기업 선별 | “성숙 고성장”보다 **초입(early confirmed)** 이 타깃 |
| **2** | 성공 기준은 **다양한 팩터를 종합 점수**로 | 단일 KPI(등가만, SPX만) 금지 |
| **3** | **Fund 함수는 1·2 해결 후** 수정 | 이번 계획의 Phase A/B에서는 `fundamental` 가중치·채점식 **동결** |

전략 문장:

> Stage 2(가격 확인) 위에서, **실적·가격 양쪽으로 “성장이 방금 확인되기 시작한”** 종목을 골라  
> 그 추세에 올라탄다. 성패는 다팩터 종합 점수로 판정한다.

## 2. 현재 모델과의 정합 / 갭

### 이미 맞는 것

- Trend Template = **가격으로 확인된** 상승 구간만 허용 → “확인 후 탑승”과 일치
- Fund의 가속도(B/D)·서프라이즈(S) = **실적 쪽 확인** 재료 (다만 아직 “초입” 판별기는 아님)
- Soft ceiling = RS만 폭주한 종목 억제 → 근거 없는 기대 과열과 구분

### 아직 없는 것 (이번 계획이 채울 갭)

| 갭 | 설명 |
|---|---|
| **초입(early) 정의** | “성장이 방금 시작”을 코드 가능한 규칙으로 없음 |
| **확인(confirmed) 이중 확인** | 가격·실적·(선택)수급을 **한 점수로 묶는 게이트** 없음 |
| **다팩터 성공 점수** | as-of 백테스트·`!검증`이 각각 있지만 **종합 성적표 1개**가 없음 |
| Fund 개편 | **의도적으로 보류** (Phase C) |

## 3. 범위 / 비범위

### 한다 (Phase A → B)

1. **Early-Confirmed Growth (ECG) 정의·플래그·점수** (Fund 식은 그대로 두고, **기존 출력·부가 컬럼**으로 구현)
2. **Composite Success Score (CSS)** — as-of·라이브 공통 성적 채점표
3. ECG 후보 vs 기존 sepaTop/median+ **as-of 전방 비교**
4. 문서·리포트에 “초입 확인 성장” 해석 문장

### 안 한다 (이번 범위 밖)

- `fund_score` 가중치(S47/E25/…) **변경**
- Trend Template 8조건 완화로 “미확인 기대주” 유입
- 자동매매·체결 엔진 (Phase 5) 부활
- Forward 컨센서스(애널 기대성장률) 본선 편입 — **확인 성장** 원칙과 충돌 가능 → Phase C 후보로만

## 4. 핵심 개념 — Early-Confirmed Growth (ECG)

### 4.1 비유

- ❌ “언젠가 클 것 같다” (기대만)
- ❌ “이미 5년째 초고성장 + RS 99만” (너무 늦었을 수 있음 · 초입 아님)
- ✅ “가격은 Stage 2로 **확인**됐고, 실적/가격 신호상 성장 스토리가 **방금 꺾어 올라온** 구간”

### 4.2 확인(Confirmed) — 둘 다 필요 (AND)

| 축 | 최소 조건 (초안 · 튜닝 대상) | 데이터 |
|---|---|---|
| **C1 가격 확인** | Stage 2 통과 + RS≥70 (현행 live와 동일) | screener |
| **C2 실적 확인** | Fund 구성 중 **가속·서프라이즈 중 ≥1개가 양수 기여** 또는 Fund≥풀 중앙값 | 현행 `fundamental_*.csv` (식 변경 없음) |

> Fund **공식을 바꾸지 않고** 컬럼·플래그만 읽는다.

### 4.3 초입(Early) — “방금 시작” 휴리스틱 (OR 조합 → 점수화)

초입은 **단일 하드컷보다 점수**로 가는 것이 2번 요구와 맞다.  
아래는 **초안 팩터** (구현 전 가중치 확정).

| ID | 초입 신호 | 직관 | 계산 스케치 |
|---|---|---|---|
| **E1** | RS가 “너무 극단”이 아님 | 이미 다 오른 끝물 회피 | RS ∈ [70, 90) 가점, RS≥95 감점(또는 soft 통과군만 소폭 가점) |
| **E2** | 52주 고점 근접이되 **돌파 직후·미연장** | 베이스 탈출 초입 | `close`가 52주 고점 대비 −25%~+5% 밴드; +15% 이상 연장 감점 |
| **E3** | 실적 가속도가 **최근 분기에 막 양전** | 성장 “시작” | B 또는 D가 직전≤0 → 이번>0 (턴업). 연속 3분기 만점 가속은 “초입” 감점 |
| **E4** | SMA200 상승 전환 최근성 | 장기 추세 초입 | `trend_days` 창에서 SMA200이 하락→상승으로 바뀐 지 **N일 이내** |
| **E5** | VCP FORMING/WATCH 또는 수축 후 돌파 직전·직후 | 타이밍 초입 | 기존 `vcp_timing` 상태 (shortlist 단계에서) |
| **E6** | 시총·유동성 게이트 | 초소형 노이즈 제외 | 현행 ≥$1B 유지 |

**ECG 점수 (초안):**

```
ECG = wC·ConfirmedGate(0|1) × (w1·E1 + w2·E2 + w3·E3 + w4·E4 + w5·E5)
```

- ConfirmedGate=0 이면 ECG=0 (확인 안 된 종목은 후보 탈락)
- 가중치 `w*` 합=100, **첫 버전은 균등 또는 E3·E1 약간 가중** → as-of로 튜닝
- **Fund 본문 미수정**: E3는 기존 `b_raw`/`d_raw`/플래그 파생

### 4.4 라이브 출력 (Fund 수정 전)

| 산출 | 내용 |
|---|---|
| `reports/ecg_YYYYMMDD.csv` | ticker, RS, Fund, E1…E5, ECG, rank |
| go/anal 옵션 또는 후속 매크로 `!sepa.ecg()` | ECG 상위·복사용 문자열 |
| soft_drop / median+과 **병기** | 기존 정책 유지 + ECG는 **추가 렌즈** |

기존 RS soft ceiling·median+ **삭제하지 않음** (비교 기준선 유지).

## 5. 핵심 개념 — Composite Success Score (CSS)

성공을 “한 숫자로만” 말하지 않고, **여러 팩터를 점수화한 성적표**.

### 5.1 평가 단위

- **1차:** as-of 월말 격자 (현행 캐시에서 1Y 전방 가능 분 ≈ 11장, 확장 시 더)
- **2차:** 라이브 go 스냅샷 누적 시 `!검증` A–D와 조인

### 5.2 팩터 메뉴 (종합 채점)

각 팩터 0–100 → 가중 합 = **CSS**.

| ID | 팩터 | 측정 | 높은 점수 의미 |
|---|---|---|---|
| **S1** | 벤치 초과 (등가) | EW − SPX, EW − QQQ (1M/3M/6M/1Y) | 바스켓이 지수를  systematically 이김 |
| **S2** | 벤치 초과 (중앙값) | Med − SPX, Med − QQQ | “다수 종목”도 이김 (홈런만 아님) |
| **S3** | 승률 | as-of 중 EW>SPX / Med>SPX / EW>QQQ 비율 | 운 한 방이 아님 |
| **S4** | 꼬리 의존 패널티 | \|Mean − Median\| 또는 P90−P50 | 클수록 **감점** (복권형) |
| **S5** | 중단기 안정 | 3M·6M에서도 S1·S2 붕괴 없는지 | 1Y만 좋은 착시 방지 |
| **S6** | 하방 | P10, 최대낙폭 근사(가능 시) | 위험조정 |
| **S7** | 회전·지속 | 멤버십 교체율, presence | 초입 후보가 매번 전부 바뀌면 감점 |
| **S8** | 섹터 집중 패널티 | 상위 1–2 섹터 비중 | 테마 베타만으로 CSS 부풀리기 방지 |
| **S9** | (선택) ECG 리프트 | ECG 상위 분위 vs 전체 Stage2 / vs median+ excess | “초입 렌즈”가 실제로 돕는지 |

**권장 초기 가중 (합 100, 튜닝 전):**

| S1 | S2 | S3 | S4 | S5 | S6 | S7 | S8 | S9 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 20 | 20 | 15 | 15 | 10 | 10 | 5 | 5 | (비교군에만) |

### 5.3 판정 문장 규칙

- CSS는 **절대 합격선**보다 **베이스라인 대비 ΔCSS**로 말함  
  - 베이스라인 A: 현행 soft ceiling 후 풀 (sepaTop)  
  - 베이스라인 B: Fund≥중앙값  
  - 후보: ECG 상위 N% 또는 ECG≥임계  
- 표본 n as-of < 10 이면 CSS 옆에 **「자료 부족」** 고정 (기존 `!검증` gate와 동일 정신)

### 5.4 산출물

| 파일 | 내용 |
|---|---|
| `reports/asof_forward_bt/css_rollup.csv` | 규칙별 CSS·팩터 분해 |
| `reports/charts/css_compare_*.png` | 베이스라인 vs ECG |
| `docs` 요약 표 | 의사결정용 한 페이지 |

재사용: 기존 `sepa.asof_forward_bt`, `perf_ledger`, `perf_study`.

## 6. 단계별 실행 계획

### Phase A — 정의·측정 (Fund 미수정) ← **지금 할 일**

| 단계 | 할 일 | 완료 기준 (DoD) |
|---|---|---|
| **A0** | 본 문서 승인 (가중치·초입 휴리스틱 합의) | 사용자 OK |
| **A1** | ECG 파생 모듈 `sepa.ecg` — 기존 CSV만 읽어 E1–E4(+E5 가능 시) 계산 | 단위 테스트 + 1일 go 산출 `ecg_*.csv` |
| **A2** | CSS 모듈 `sepa.css_score` — as-of summary → 팩터·총점 | 11 as-of에 대해 sepaTop·median+ CSS 산출 |
| **A3** | 동일 격자에서 ECG 상위 바스켓 forward + CSS 비교 | 표+차트 1세트, 룩어헤드·생존편향 캡션 |
| **A4** | 결과 해석: ECG가 ΔCSS>0인지 / 어느 팩터(S2·S4)가 개선인지 문서화 | `docs/ecg_css_pilot_YYYYMMDD.md` |

**A상 성공이면:** “초입 확인 성장 렌즈가 **현행 풀보다 나은 근거**가 있는지”에 예/아니오/자료부족으로 답 가능.

### Phase B — 정책 연결 (여전히 Fund 식 동결)

| 단계 | 할 일 | 조건 |
|---|---|---|
| **B1** | live 정책 후보: `median+` ∩ `ECG≥τ` 또는 ECG 상위 K를 **추천 레이어**로 표시 | A3에서 ΔCSS 안정적 플러스 |
| **B2** | `!검증` 또는 go 요약에 CSS 한 줄·ECG 복사용 문자열 | 사용자 UX 승인 |
| **B3** | soft ceiling과 ECG 충돌 시 우선순위 문서화 | 예: soft drop은 유지, ECG는 통과군 안에서만 |

### Phase C — Fund 함수 수정 (사용자 요구: **A·B 이후**)

Phase A/B 결과가 나온 뒤에만 착수.

| 후보 | 동기 | 전제 |
|---|---|---|
| 초입 가속(턴업) 가중 ↑ | E3를 Fund 본문에 흡수 | ECG 리프트가 S2·S4에서 입증 |
| 절대 YoY 수준 소량 복귀 | “성장은 확인됐지만 가속만으로는 얕음” | 이벤트/as-of 재스터디 |
| Surprise 과가중 완화 | 일회성 비트 ≠ 초입 성장 | 동일 |
| Forward 기대 레이어 | **비확인 기대**라 본선 금지 원칙과 충돌 가능 → 보조 라벨만 검토 | 별도 승인 |

**Phase C 진입 게이트:** A3에서 ECG 바스켓이 베이스라인 대비 CSS **동일 격자·동일 벤치**로 개선하거나, “개선 없음”이 문서화되어 **다른 Fund 가설**로 전환할 근거가 있을 것.
