## 1. 핵심 질문과 공식 판정

**질문:**  
초입 확인 성장(ECG) 렌즈가 현행 풀(sepaTop · median+)보다 **나은 근거**가 있는가?

| 판정 | 선택 |
|------|------|
| 예 (채택 근거 충분) | |
| 아니오 (열등·실패 기준 충족) | |
| **자료 부족** (신호는 있으나 확증 불가) | **← 공식 답** |

### 한 줄 요약

ECG top은 기준선 대비 **ΔCSS +1.8~+2.5**이고, 목표 팩터인 **S2(중앙값 초과)·S4(꼬리 의존)** 가 함께 개선되었다.  
다만 **n_asof=11**, 생존편향, S3/S7 악화가 있어 **라이브 본선 채택(Phase B 본선) 근거로는 부족**하다.

| rule | EW−SPX | Med−SPX | \|EW−Med\| | EW>SPX | Med>SPX |
|------|-------:|--------:|----------:|-------:|--------:|

“지수보다 확실히 이긴다”가 아니라 “복권형 의존이 덜하다”에 가깝다.

## 6. 팩터별 해석

| 팩터 | ECG 방향 | 해석 |
|------|----------|------|
| **S2** | ↑↑ | 파일럿의 핵심 성과. 중앙값도 지수에 근접(1Y Med−SPX ≈ 0). |
| **S4** | ↑ | 등가−중앙 간격 축소 → 소수 대박 의존 완화. |
| S6 | ↑ | P10 하방도 상대적으로 나음. |
| S1 | ↓ | 등가 초과는 기준선(특히 median+)보다 약함. “평균 수익 극대화” 렌즈는 아님. |
| S3 | ↓ | as-of 단위 승률↓ — 작은 바스켓·구간 변동. |
| S7 | ↓↓ | 상위 10–17종만 골라 회전↑. 초입 정의상 어느 정도 예상됨. |
| S5/S8 | ≈ | 안정·섹터는 유사. |

전략 정합: 원래 목표(“확인된 성장의 **초입**에 올라타며, 홈런만으로 말하지 않기”)와 **S2/S4 개선이 정합**.  
S1 극대화나 매 구간 승률 극대화와는 **부분적으로 긴장**.
