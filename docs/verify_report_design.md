## 1. 한 줄 콘셉트

`!검증` = **“우리 SEPA 스크리너, 요즘 성적 어때요?”** 에 답하는 **짧은 한글 보고서 PDF**.

```text
!검증
  → reports/perf/검증보고서_YYYYMMDD.pdf
  → GitHub Release 업로드 (sepa-검증-YYYYMMDD)
  → 콘솔에 PDF 직접 다운로드 URL + 릴리즈 페이지 URL 출력
```

숫자는 D29 A–D 패널 그대로, **말·레이아웃·배달만 보고서화**.

## 3. 8쪽 목차

1. 한눈에 — 질문 4개 Yes/No/모름 + 신뢰 배지  
2. 보는 것 / 안 보는 것 + 용어 사전  
3. A. 바구니 성적  
4. D. soft ceiling 검사  
5. B. 들어옴 / 나감  
6. C. 오래 남음  
7. 후보 규모 추이  
8. 부록 원표  

자동 문장 = 고정 템플릿 + 숫자 슬롯 (LLM 없음).
